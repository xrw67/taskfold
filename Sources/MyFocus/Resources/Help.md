# MyFocus 使用帮助

MyFocus 是一款类 OmniFocus 的 macOS 本地待办应用：所有数据保存在本机（无账号、无联网），配合 **GTD 工作流**（收集 → 整理 → 执行 → 完成）组织日常事务。

---

## 快速上手

1. **收集**：按 ⌘N 随手把想到的事记进**收件箱**，不必立刻想清楚细节。
2. **整理**：把收件箱里的任务拖到左侧对应**项目**，需要时在检查器里补上截止日期。
3. **执行**：切到**今天**视图（⌘2），按「逾期 / 今天 / 未来 7 天」三段安排当天工作。
4. **回顾**：完成的任务按 Space 标记完成；确定不再做的按 ⌥Space 放弃（保留记录，不删除）。

## 界面导览

### 侧边栏

- **收件箱**：未指定项目的任务都在这里，是 GTD 的收集箱。
- **今天**：带截止日期的任务按「逾期 / 今天 / 未来 7 天」分组显示。
- **项目**：同类任务的集合，项目名旁的数字是其中未完成的任务数；上下拖动项目行可调整顺序。
- 把大纲中的任务**拖到侧边栏**，即可移动到收件箱或某个项目（子任务自动跟随）。

### 任务大纲

- 中间主区域按层级展示任务，子任务支持**任意层级嵌套**。
- **双击**任务名进入行内重命名，Esc 取消；回车在下方插入新任务并继续编辑。
- 拖动任务行可排序：拖到目标行的**上下边缘**表示插到它前面 / 后面，拖到**中部**则成为它的子任务，悬停时会出现插入线或淡色底提示。
- 每个任务的**展开/折叠状态会被记住**，重启应用后保持。
- 顶栏搜索框（⌘F）实时过滤，命中的文字会高亮；Esc 清空并退出。

### 检查器

选中任务后右侧显示详情：状态、所属项目、截止日期（点开有迷你日历和「今天 / 明天 / +1 周 / 清除」快捷按钮）、备注。⌘⌥I 显示 / 隐藏检查器。设置（⌘,）中可配置新任务的默认截止时刻。

## 快捷键

### 全局命令

| 键 | 功能 |
| --- | --- |
| ⌘N | 新建任务（当前区域） |
| ⌘F | 聚焦搜索（Esc 清空并退出） |
| ⌘⌥I | 显示 / 隐藏检查器 |
| ⌘1 / ⌘2 / ⌘3 | 切到收件箱 / 今天 / 第一个项目 |
| ⌘⌫ | 删除选中任务（连同全部子任务） |
| ⌘, | 打开设置 |
| ⌘? | 打开本帮助 |

### 大纲键盘操作

| 键 | 功能 |
| --- | --- |
| Space / ⌥Space | 完成 / 放弃选中任务 |
| 回车 | 在下方插入任务并进入编辑；编辑中回车 = 确认并续行 |
| Tab / ⇧Tab | 缩进为子任务 / 提升一级（子树自动跟随） |
| ⌥↑ / ⌥↓ | 同级内上移 / 下移 |
| ↑ / ↓ | 按可见行顺序移动选中（跨层级、自动滚动；无选中时 ↓ 选首行、↑ 选末行） |
| → / ← | 展开 / 折叠子任务；已展开时 → 进入第一个子任务，无子任务时 ← 选中父任务 |
| 双击 | 行内重命名（Esc 取消） |

大纲快捷键不依赖列表焦点，任意焦点状态下都有效；正在输入文字时自动放行给文本框。

## 任务状态

| 状态 | 含义 |
| --- | --- |
| 进行中 | 默认状态，计入侧边栏徽章与「今天」视图 |
| 已完成 | Space 切换 |
| 已放弃 | ⌥Space 切换，留档不删除 |

完成、放弃、恢复和删除都会**递归作用于整棵子任务树**，不必逐个处理子任务。

## 数据与备份

- 数据保存在本机 ~/.config/MyFocus/MyFocus.sqlite，纯本地单文件，方便整库备份或迁移到新电脑。
- **当天首次启动**会自动做一份备份；也可随时「文件 → 立即备份」。
- 备份默认保留最近 **20 份**（可在设置中调整）；在**设置 → 备份**中查看与恢复，恢复为在线热替换，**无需重启应用**。
- 旧版本目录 ~/Library/Application Support/MyFocus/ 中的数据会在启动时自动一次性迁移。

## 导入与导出

**导入**（「文件 → 导入…」）接受 MyFocus 导出的 CSV / OPML 文件：

- 导入前自动创建一份备份（可在「设置 → 备份」恢复），误导入可回退。
- 与现有**同名项目自动合并**，不会新建重复项目；任务按原层级与顺序追加到各列表末尾。
- CSV 保真度最高（备注、状态、截止、创建时间齐全）；OPML 保留层级、状态与截止。

**导出**（「文件 → 导出为」）支持三种格式：

| 格式 | 用途 |
| --- | --- |
| CSV 表格 | 带 BOM，Excel / Numbers 打开中文不乱码；可再导入 |
| OPML 大纲 | 可导入其他大纲类工具；可再导入 |
| Markdown | GFM 任务列表，Obsidian / GitHub 可直接渲染；不支持导入 |

## 常见问题

- **数据存在哪里？怎么整体备份？** 见上文「数据与备份」；最简单的方式是定期拷贝整个 ~/.config/MyFocus/ 目录。
- **误删了任务怎么办？** 在「设置 → 备份」中恢复删除前的最近一份备份。
- **收件箱里的任务怎么归入项目？** 拖到侧边栏对应项目，或在检查器中修改所属项目。
- **示例数据能删吗？** 首次启动创建的示例任务与普通任务一样，可直接删除。
