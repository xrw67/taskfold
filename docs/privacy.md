# Taskfold 隐私政策

生效日期：2026-09-30

Taskfold（下称「本应用」）是一款本地优先的待办事项与任务管理应用。我们极其重视你的隐私——本应用的全部设计都围绕「你的数据只属于你」。

## 我们不收集任何数据

- 本应用**不联网**：没有任何网络请求，不包含任何分析、统计、广告或第三方 SDK。
- 你的全部数据（任务、项目、备注、截止日期、备份、偏好设置）**仅存储在你的 Mac 本地**（应用沙盒容器内），**不会上传**到任何服务器——因为没有服务器。
- 我们无法访问、无法恢复、也无法删除你的数据。

## 数据的存储与备份

- 数据保存在本应用的沙盒容器内，路径见「设置」页显示的数据库路径。
- 本应用会在本地自动创建每日备份，可在「设置」中查看与恢复。
- 卸载本应用会连同容器一起删除全部数据，卸载前请先用「文件 → 导出」自行留存。

## 数据的导出与导入

你可以随时通过「文件 → 导出」将全部数据导出为 CSV / OPML / Markdown 文件（导出位置由你指定），并通过「文件 → 导入」恢复。导出文件完全由你掌控。

## 权限使用

本应用仅在你主动使用「导入 / 导出」时，通过系统文件面板访问你选定的文件，不做任何其他文件访问。不请求通讯录、位置、相机、麦克风等任何其他权限。

## 儿童隐私

本应用不收集任何数据，适合所有年龄段使用。

## 联系方式

如有疑问，请通过 GitHub 仓库反馈：https://github.com/xrw67/taskfold

---

*本政策自上述生效日期起适用。由于本应用永不联网，本政策未来也不会出现「收集数据」相关的变更。*
