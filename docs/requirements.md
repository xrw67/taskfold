## 1. 项目概述

开发一个**类 OmniFocus 的 macOS 本地待办管理应用**，以"项目"为中心管理个人待办，遵循 GTD 工作流（收集 → 整理 → 执行 → 完成）。

- **本地优先**：数据全部存储本机（SQLite），无账号、无联网要求。
- **键盘效率**：大纲直接键盘编辑，对标 OmniFocus 的操作手感。
- **原生体验**：SwiftUI，遵循 macOS HIG，深色模式。

**不做**：iOS/Web 客户端、多人协作、位置提醒（Nearby）、插件系统、自建云同步（iCloud 同步远期可选）。

## 2. 第一版（V1）范围推荐 —— 只做 5 个核心功能

OmniFocus 功能面极广（透视/标签/重复/回顾/自动化……），第一版若全面对标必然烂尾。V1 的目标是**能每天真实用起来的最小闭环**：捕获 → 整理 → 执行 → 完成。其余功能都是放大器，不是地基。

| # | 核心功能 | 一句话说明 |
| --- | --- | --- |
| 1 | **任务与项目** | 项目、任务、一层子任务；完成/放弃/恢复；键盘大纲编辑 |
| 2 | **收件箱** | 快速捕获未整理任务，手动分配到项目后自动移出 |
| 3 | **截止日期 +「今天」视图** | 截止时间、逾期/今天/未来 7 天三段视图、黄红颜色语义 |
| 4 | **检查器** | 右侧属性面板：标题/所属项目/截止/备注/元数据 |
| 5 | **本地存储 + 搜索** | SQLite 持久化、⌘F 全文搜索、基础快捷键集 |

**V1 明确不做**（推迟到 V2/V3，见 6.2/6.3）：标签、旗标、推迟日期（Defer）、顺序/并行项目类型、多级嵌套行动组、文件夹、重复任务、系统提醒通知、自定义透视、Forecast 完整版（琴键+月历+日历）、全局 Quick Entry、Quick Open、自然语言日期、备份导出、多窗口、菜单栏常驻。

**V1 简化原则**：
- 所有项目一律视为并行（不做顺序/单动作列表区分）。
- 界面固定三个视图：**收件箱 / 今天 / 项目**，无透视栏概念。
- 备注纯文本（富文本 V2）。
- 未指定项目的任务 = 收件箱任务；指定项目即完成整理（无 Clean Up 规则引擎）。

## 3. 目标用户与场景

**目标用户**：使用 Mac 的个人开发者/知识工作者，管理多个项目（工作、side project、生活）的待办，认同 GTD 方法论，重视数据隐私与本地存储。

| # | 场景 | V1 对应功能 |
| --- | --- | --- |
| S1 | 想到一件事，几秒内记下来，稍后整理 | 收件箱、应用内快捷新建 |
| S2 | 每天开工先看今天要做什么、什么逾期了 | 「今天」视图、颜色徽章 |
| S3 | 把收件箱杂项归到项目、设截止日 | 检查器、拖拽分配 |
| S4 | 规划项目：拆步骤、勾掉完成 | 项目+子任务、键盘编辑、状态圈 |

## 4. 竞品调研摘要（OmniFocus 4 for Mac）

> 完整调研结论的依据与截图分析见参考资料；此处仅保留影响需求的部分。

### 4.1 GUI 布局

三栏式：**透视栏+侧边栏（左）/ 大纲（中）/ 检查器（右）**。

- 透视栏：一列可排序的透视图标页签（Inbox/Projects/Tags/Forecast/Flagged…）；侧边栏内容随透视切换（项目树带徽章 / 标签树 / 月历），是标准半透明 Source List。
- 大纲区：顶部透视名+计数；行结构 `状态圈 | 旗标 | 标题 | 附属信息（截止日/项目/标签/备注图标）`；两种布局——Fluid（流式，默认，显示+编辑两套字段）与 Columns（列式，单行平铺可选列）。
- 检查器：随选中对象切换的属性面板，分区卡片（状态/日期/重复/提醒/归属/备注）。
- 颜色语义（状态圈）：黄=即将到期、红=逾期、橙+旗=已标记、三点=重复、✓=完成、—=放弃，可叠加。

### 4.2 核心概念

| 概念 | 说明 |
| --- | --- |
| Inbox | 捕获池；整理后 Clean Up 自动清空 |
| Project | 任务容器；类型：并行/顺序/单动作列表；状态：Active/On Hold/Completed/Dropped |
| Action Group | 任务内嵌套子任务，可多层，组可并行/顺序 |
| Folder | 项目分组，可嵌套 |
| Tag | 可嵌套、可多选的上下文标签（替代 Context） |
| Flag | 独立于日期的软优先级标记 |
| Defer / Due | 双日期体系：推迟至（变为可用）/ 截止（硬期限） |
| Repeat | 按"完成时间"或"指定日期"为基准重复；支持周几、每月第 N 个星期几 |
| Review | 每项目独立回顾周期与下次回顾日期 |
| 继承规则 | 日期/状态/旗标从容器继承；标签仅首次加入时继承一次 |
| 透视 | 一套"过滤+分组+排序+布局"的视图配置；9 个内置 + 自定义（Pro） |

### 4.3 内置透视（9 个）

Inbox（收集）、Projects（规划）、Tags（按上下文找事）、Forecast（时间视角：琴键日期磁贴+日历事件内联）、Flagged（旗标清单）、Nearby（位置，不做）、Review（回顾）、Completed / Changed（历史）。

### 4.4 效率设计（V2 主要借鉴对象)

全局 Quick Entry（⌥Space 系统级呼出录入窗）、Quick Open（⌘O 模糊跳转）、裸键编辑（无焦点时单键触发常用操作）、自然语言日期（"next Thursday"、"2w sat"）、完整拖拽赋值体系（拖到侧边栏=改归属/加标签，拖到日期=设截止）。

## 6. 功能需求

### 6.1 V1（第一版）详细需求

#### 数据与存储

| 编号 | 需求 |
| --- | --- |
| DS-1 | SQLite 本地单文件存储，完全离线可用；设置中展示库文件路径 |
| DS-2 | 任务字段：标题、备注（纯文本）、所属项目、父任务（最多一层）、状态（Active/Completed/Dropped）、截止日期（可选时间）、创建时间、修改时间、排序位置 |
| DS-3 | 项目字段：标题、状态（Active/Completed/Dropped）、备注、排序位置；V1 无文件夹、无类型区分（全并行） |
| DS-4 | 完成或放弃项目时级联处理未完成任务 |
| DS-5 | WAL 模式，异常退出不丢数据 |

#### 任务与项目

| 编号 | 需求 |
| --- | --- |
| TP-1 | 大纲键盘编辑：回车续行、Tab 缩进为子任务、⇧Tab 提升、⌥↑↓ 移动行、⌘⌫ 删除 |
| TP-2 | 状态圈：点击=完成（✓ 绿、划线灰显）、⌥点击=放弃（— 灰）、再点恢复；Space 完成 / ⌥Space 放弃 |
| TP-3 | 侧边栏项目列表：徽章显示剩余数与逾期数（红）；支持重命名与删除 |
| TP-4 | 删除项目时二次确认，任务移回收件箱（不连带删除） |
| TP-5 | 已完成任务的显示开关（默认显示划线灰显，可关闭；偏好持久化） |

#### 收件箱

| 编号 | 需求 |
| --- | --- |
| INB-1 | 未指定项目的任务进入收件箱；侧边栏"收件箱"显示计数徽章 |
| INB-2 | 检查器中指定项目后，任务立即移出收件箱 |
| INB-3 | 拖拽任务到侧边栏项目 = 分配该项目 |
| INB-4 | ⌘N 快捷新建任务到当前视图；空收件箱显示"Inbox Zero"引导插画 |

#### 截止日期与「今天」视图

| 编号 | 需求 |
| --- | --- |
| DT-1 | 截止日期设置：图形日历+时间选择器；快捷按钮（今天/明天/+1 周/清除）；时间可选（无时间=当天全天，按当天 17:00 处理，可在设置改默认时刻） |
| DT-2 | 颜色语义：黄=即将到期（默认窗口=今天内，可配置）、红=逾期；状态圈与侧边栏徽章一致 |
| DT-3 | 「今天」视图固定三段分组：**逾期 / 今天 / 未来 7 天**；无日期任务不出现 |
| DT-4 | 每段显示任务所属项目，便于跨项目扫读 |

#### 检查器

| 编号 | 需求 |
| --- | --- |
| INS-1 | 右侧面板，随选中对象（任务/项目）切换；⌘⌥I 或工具栏按钮显隐 |
| INS-2 | 任务检查器：标题、所属项目（可搜索下拉）、截止、备注、只读的创建/修改时间 |
| INS-3 | 项目检查器：标题、状态（Active/Completed/Dropped）、备注、只读统计（剩余/逾期数） |

#### 键盘与搜索

| 编号 | 需求 |
| --- | --- |
| KB-1 | 视图切换：⌘1 收件箱 / ⌘2 今天 / ⌘3 项目 |
| KB-2 | ⌘F 搜索：匹配任务与项目标题+备注，结果高亮，可开关"包含已完成" |
| KB-3 | 所有命令在菜单栏可用（符合 macOS 规范） |

#### V1 实现记录（2026-09-28）

6.1 全部需求已实现并通过 27 个单元测试（`make test`）。三处偏差：

- **DT-2**：「即将到期」窗口 V1 固定为"今天内"，窗口可配置移至 V2。
- **TP-1**：行间拖拽重排移至 V2（键盘移动 ⌥↑↓ 已实现）；拖拽到侧边栏分配项目（INB-3）已实现，子任务随顶层任务一起移动。
- **7.3**：示例数据未提供「一键清除」按钮（删除示例项目与收件箱示例任务即可，删除均有确认框），按钮移至 V2。

#### 2026-09-29 补充：多层级大纲与键盘可靠性

- **多级行动组提前实现**（原属 6.2/V2）：子任务支持任意层级嵌套。Tab 缩进为同容器前一个兄弟的子任务；⇧Tab 提升一级（非直接到顶层）；缩进/提升时子树经 parentID 链自动跟随；删除与完成/放弃/恢复均递归作用于整棵子树。
- **键盘路由重构**：大纲快捷键（Tab/⇧Tab/回车/⌥↑↓/Space/⌥Space）改由应用级 NSEvent monitor（KeyboardRouter）接管。原菜单 key equivalent 方案对无修饰键 Tab 无效（被系统焦点循环吞掉）、.onKeyPress 依赖 List 焦点，两条旧路径均不可靠。文本编辑上下文（行内编辑/搜索框/检查器文本框）自动放行；无效操作（首个任务缩进、顶层再提升）播放提示音。
- 术语表与 6.2 的「多级行动组」条目已同步更新；测试增至 32 个。

#### 2026-09-30 补充：备份与导出（DATA-1/DATA-2 提前实现）

- **备份（DATA-1）**：当天首次启动自动创建 SQLite 快照（GRDB online backup，WAL 安全）；文件菜单「立即备份」；设置窗口管理备份（时间/大小/恢复/在 Finder 显示）；恢复为在线热替换（反向 backup，无需重启应用）；保留份数默认 20、设置可调（1–200）。
- **导出（DATA-2）**：文件菜单「导出为」CSV（UTF-8 BOM + RFC 4180 转义）/ OPML 2.0（项目与多级任务嵌套 outline）/ Markdown（GFM 任务列表，`- [ ]`/`- [x]`/`~~放弃~~`，截止与逾期标注）。导入（CSV/OPML）仍留在后续版本。
- 测试增至 47 个。

### 6.2 V2（第二版）

- **标签**：可嵌套、可多选、标签管理视图。

- **导入**（CSV/OPML）：OmniFocus/Things 迁移。（备份与导出已于 2026-09-30 提前实现，见上）

## 7. GUI 需求（V1）

### 7.1 布局（V1 简化版三栏，无透视栏）

```
┌──────────────────────────────────────────────────────────────────────────┐
│  MyFocus        [⌘F 搜索框]                [□检查器] [＋新建 ⌘N]           │ ← 工具栏
├──────────────┬───────────────────────────────┬───────────────────────────┤
│ 侧边栏        │ 大纲区                        │ 检查器                    │
│ ──────────── │ ──────────────────────────── │ ──────────────────────── │
│ 📥 收件箱  ③ │ 今天                          │ 标题                      │
│ ⭐ 今天   ② │ ├ 逾期                        │ [状态▾]                   │
│ ▾ 项目       │ │  ● 任务 X  ⚑ 前天截止       │ ─────────────            │
│   · 网站改版 │ ├ 今天                        │ 项目 [网站改版 ▾]         │
│   · 读书计划 │ │  ○ 任务 Y        今天 17:00 │ 截止 [明天 09:00    ▾]   │
│              │ └ 未来 7 天                   │ ─────────────            │
│              │    ○ 任务 Z     周五 截止     │ 备注                      │
│              │                               │ [                    ]   │
│              │                               │ ─────────────            │
│              │                               │ 创建于 09-01 · 改于今天   │
├──────────────┴───────────────────────────────┴───────────────────────────┤
│  状态栏：选中项信息 / 存储状态                                              │
└──────────────────────────────────────────────────────────────────────────┘
```

- 三栏宽度可拖拽调整并记忆；检查器隐藏时大纲占满（⌘⌥I）。
- 侧边栏：收件箱 / 今天 / 项目列表（带徽章），标准 Source List，跟随系统外观（深/浅色）。

### 7.2 行设计

- 结构：`状态圈 | 标题 | 附属信息（截止日，所属项目）`；容器（项目/父任务）加粗。
- 状态圈颜色：黄=即将到期、红=逾期、✓ 绿=完成、— 灰=放弃；有子任务的父任务显示进度（如 2/5）。
- 行悬停显示备注图标；选中行时检查器同步。

### 7.3 空状态与引导

- 收件箱空 → "Inbox Zero"插画；项目空 → 提示添加第一个任务。
- 首次启动提供示例数据（1 个项目 + 几个任务），可一键清除。

## 9. 技术选型建议（供参考）

| 层 | 建议 | 理由 |
| --- | --- | --- |
| UI | SwiftUI（全局快捷键等少量 AppKit） | 原生观感、开发效率 |
| 存储 | GRDB.swift（SQLite）或 SwiftData | M0 用 1 万条数据基准测试定夺；GRDB 可控性强，SwiftData 与 SwiftUI 集成省事 |

| V2 通知 | UserNotifications | 本地提醒 |
| V3 日历 | EventKit 只读 | Forecast 事件 |
